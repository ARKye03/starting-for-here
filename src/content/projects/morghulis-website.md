## Project Overview

Astro web for the Morghulis Desktop Shell.

- Responsive design
- Dark/Light mode
- Smooth animations

## Technologies Used

- Astro
- GSAP
- TailwindCSS
- TypeScript

## Results

Simple, yet modern website, showcasing and helping installation and configuration of the Morghulis Desktop Shell.

Using GSAP and Astro to provide great animations and UX while keeping it all efficient and pretty.
