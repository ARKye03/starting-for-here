## Descripción del Proyecto

Sitio web en Astro para el Shell de Escritorio Morghulis.

## Características Clave

- Diseño responsivo
- Modo claro/oscuro
- Animaciones fluidas

## Tecnologías Utilizadas

- Astro
- GSAP
- TailwindCSS
- TypeScript

## Resultados

Un sitio web simple pero moderno, que muestra y ayuda en la instalación y configuración del Shell de Escritorio Morghulis.

## Idea

Usar GSAP y Astro para proporcionar excelentes animaciones y experiencia de usuario, manteniendo todo eficiente y atractivo.
