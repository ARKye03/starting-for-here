## Descripción del Proyecto

**larasdelitesse** es una aplicación web moderna construida con un backend en Laravel y un frontend en ReactJS que permite añadir y gestionar fácilmente proyectos de tiendas/delis. Utiliza un sistema de archivos estructurado para el contenido de los proyectos y proporciona una experiencia optimizada para mostrar cada proyecto con detalles basados en Markdown, imágenes y metadatos.

## Características Clave

- Generación automática de páginas y listado por proyecto
- Frontmatter para metadatos enriquecidos del proyecto (etiquetas, imágenes, URLs, etc.)
- Integración con ReactJS para contenido dinámico

## Tecnologías Utilizadas

- Laravel (framework PHP)
- ReactJS
- GitHub Actions

## Resultados

- Flujo de trabajo sencillo para añadir nuevos proyectos con código mínimo
- Listado, clasificación y visualización automática de proyectos por fecha y metadatos
- Fácil integración de contenido multimedia (imágenes, enlaces) por proyecto
- Código fuente y contenido fáciles de gestionar y reproducir por otros AIs o colaboradores
