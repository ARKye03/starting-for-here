## Overview

This portfolio website is built using Astro (Best Framework humankind's ever made) and Tailwind CSS (Imposible to not use it, Pinnacle of Humanity). It features a clean and modern design, showcasing various projects and services. The site is fully responsive and optimized for performance. It is made to scale as I grow with time.

## Features

- Responsive Design: The website is designed to look great on all devices, from desktops to mobile phones.
- Project Showcase: A dedicated section to highlight various projects with descriptions and links.
- Contact Form: A simple contact form for visitors to get in touch.
- Basically, it's a personal portfolio site to showcase my work and skills. Just that, what else?
